Perguntas frequentes

Preciso ter o TikTok Shop ativo para usar os prompts de produto?
Não. Você pode criar os vídeos com os prompts de TikTok Shop antes mesmo de ter o Shop ativo. Use o tempo de criação de conta e crescimento (usando os prompts virais) para já preparar seu banco de conteúdo de produto. Quando o Shop abrir, você já tem vídeos prontos para publicar.
Os prompts funcionam em qualquer ferramenta de IA de vídeo?
Sim, todos os prompts foram escritos em inglês para máxima compatibilidade com ferramentas de IA. Foram criados e otimizados para o Google Flow (gratuito), mas funcionam em qualquer ferramenta de geração de vídeo com IA que aceite prompts de texto. O diálogo dos personagens permanece em Português Brasileiro.
Posso usar o mesmo prompt várias vezes para criar variações?
Sim, e é altamente recomendado! As IAs de vídeo geram variações diferentes a cada geração mesmo com o mesmo prompt. Rode o mesmo prompt 3–5 vezes e escolha o melhor resultado. Você também pode fazer pequenas modificações para obter variações específicas.
Como funciona a referência de personagem nos prompts virais?
No Google Flow, você pode fazer upload de uma imagem de referência junto com o prompt. A IA tenta manter a consistência visual desse personagem no vídeo gerado. Escolha uma imagem clara, bem iluminada e no enquadramento mais próximo do que você quer gerar.
Preciso usar um produto real ou posso criar um produto fictício?
Para fins de teste e estudo, você pode usar qualquer produto nos prompts. Para publicação real no TikTok Shop, você precisa ter o produto cadastrado na plataforma e seguir as diretrizes do TikTok. Nunca publique um vídeo de produto gerado por IA como se fosse um vídeo real seu sem disclosure adequado.
Qual é a diferença entre os prompts virais e os de TikTok Shop?
Os prompts virais têm como objetivo crescer a conta — eles criam personagens e situações que geram engajamento orgânico (seguidores, curtidas, comentários) sem vender nada. Os prompts de TikTok Shop têm como objetivo vender produtos — eles simulam criadores recomendando produtos de forma autêntica.
